# Constitution

## Non-Negotiable Principles

These principles apply to all agents, skills, and workflows generated by ryo-kit. They cannot be overridden by individual agents or processes.

### Code Quality
- All code must pass linting and formatting checks before handoff
- Tests are required for new functionality

### Security
- Never commit secrets, credentials, or API keys
- Follow the principle of least privilege

### Process
- Human review is required before merging to production branches
- All changes must be traceable to a requirement or decision
